# Landing page comps

Two directions for the public landing page, inside the Signal identity. Open the HTML files in a browser (they load Geist from Google Fonts); `renders/` holds desktop (1440) and phone (390) captures.

| File | Direction |
| --- | --- |
| `variant-a.html` | **Ledger.** A real demo shot in a device frame, and a ledger beside it naming each region: your code, stand-in, not shown. |
| `variant-b.html` | **Echo.** The logo's construction at hero scale: the app's code as a solid isometric slab, the shot cast above it as the dashed yellow imitation. Then a pipeline rail, a contact sheet of one flow, agents, and limits. |

Shots in `img/` are from `demo/assets/shots` (the invented "fernwood" app) and are labelled as demo data on the pages. Agent marks are copied from `assets/agents/` under the terms in its README.

These were drawn as HTML and SVG rather than in the Paper file: the Paper MCP server runs inside the Paper desktop app and is not reachable from a cloud session. The markup can be pushed into Paper from a machine running it.
