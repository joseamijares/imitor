Your app, imitated. Every stand‑in named.

See a React Native / Expo app’s UI without a simulator. Imitor builds it for the web, swaps native-only modules for stand-ins, and runs your flows in headless Chromium.

Free and open source, MIT. Early: v0.1, on npm. Set-up takes four steps.

Every result says what it is.

Each shot, preview and agent reply lists what came from your code, what was stood in, and what Imitor cannot show. Nothing is passed off as the real phone.

From your code to a shot that says what it is.

No Mac, no emulator, no device. It runs on any Linux box, CI runner or cloud agent session. Stand-ins only apply to the web build Imitor makes; your iOS and Android builds are never touched.

  1. Build for the web

    imitor build

    Metro, wrapped with withImitor(), builds a static web version of the app.

  2. Swap in stand-ins

    expo-sqlite → sqljs

    Native-only modules get a web stand-in, and every result names which ones.

  3. Run your flows

    imitor shoot

    Taps, fills and shots in headless Chromium, once per device and colour scheme.

  4. Review

    imitor app

    Runs, captures and problems for people, or imitor export as a static site.

What it does not show.

Imitor shrinks what the final check on a real phone has to find. It does not replace that check.

  • Native navigation chrome, transitions and gestures
  • Keyboard behaviour
  • The phone’s exact font rendering
  • Entering and layout animations
  • Anything behind a stand-in
  • Platform-specific code paths: the build runs as web
  • Widgets, notifications, Live Activities, watch apps

Open source. Read it, run it, change it.

Imitor runs on your machines and in your agents’ environments. Nothing is sent anywhere unless you publish it yourself.

Imitor Cloud

A place where your agents and CI upload runs with imitor push, and you sign in to review them from any device. It only stores and shows runs, never runs your code. Its code is in the repository under AGPL-3.0, so you can host your own; a hosted version as a paid service is planned. No date and no price yet.
